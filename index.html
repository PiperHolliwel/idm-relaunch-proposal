Proposal for IDM · Website relaunch

A new idm.at, built around IDM's content and team

We recommend a custom website with its own admin panel. If IDM prefers a ready-made platform, Webflow is the alternative. Every option rebuilds the current website and moves all existing content. All accounts are owned by IDM.

Why a custom website suits IDM

◧

Made for IDM's content

About 5,000 news posts, events, publications and people, the newsletter archive and the region map each get their own place in the admin panel, with the fields IDM needs.

DE·EN

German and English side by side

Both languages are edited on one screen and keep their own addresses (English under /en). No paid language add-on.

✓

Easy for the team

Familiar from WordPress (pages, posts, events, drafts, media library, menus), plus page building from ready sections, version history and scheduled publishing.

€

Lowest running costs

About €80–130 per year for hosting, with no platform licence. Over five years this is about €1,000–2,000 less than Webflow.

EU

European hosting possible

The website, database and files can run only with European companies in the EU. Webflow offers EU hosting only on its Enterprise plan.

⌂

IDM owns it

IDM owns the code and all accounts and can change the hosting provider or developer at any time.

↗

Search results kept

About half of all visits come from Google. Old addresses stay the same or are redirected automatically.

+

Grows with IDM

Event registration, a members area or other features can be added later, without changing platform.

The admin panel

The whole team, mostly assistants and researchers, will edit the website, so the admin panel is made for non-technical users: visual, clear and quick to learn. Everyone logs in with a personal account and a role (for example admin, director, assistant). The screens are examples; the final admin panel follows IDM's design and needs.

Option 1 · Recommended

Custom website · €5,000 fixed

A website and admin panel built only for IDM. Running costs ≈ €80–130 per year, depending on hosting. Working time ≈ 17 weeks, then 3 months of support.

Included

  • Website from the final design: up to about 15 page templates, for desktop, tablet and mobile
  • Admin panel: pages from sections, news, press and blog, events, publications, people, newsletter archive, media library, menus, redirects, drafts, scheduled publishing, version history, team accounts with roles
  • All content in German and English moved from WordPress, with the same addresses where possible and redirects for the rest
  • Region map, site search, list filters, PDF archive (flipbooks replaced by a PDF viewer)
  • Google Analytics, Brevo forms, podcast, cookie banner, search engine settings
  • Accessibility following WCAG 2.1 AA
  • A test version for IDM to review before launch
  • Hosting set up in IDM's own accounts, for either hosting variant
  • Built-in "How to use" guide and two training sessions for the team
  • A technical handbook, so any developer can maintain the website later
  • 3 months of support after launch: fixes, small changes, help for editors

These figures are based on today's website: about 3,600 images and a few hundred PDFs (about 3–5 GB) and about 27 visitors a day. Hosting is paid for by use, so the cost rises only if the archive or the number of visitors grows a lot. With European providers, the website and database pause when nobody uses them, so the first page after a pause takes a few seconds; keeping them always on removes that wait and raises the cost. The first year costs the same as later years; the setup is part of the development price. If IDM needs the data to stay in Austria, Exoscale (data centres in Vienna) is also possible, at ≈ €320–640 per year.

Option 2

Webflow

Webflow is an American website platform. The website is built, hosted and edited in Webflow, and IDM pays a yearly plan. It runs on Amazon Web Services and Cloudflare in the USA; hosting in the EU is offered only on the Enterprise plan. The team edits texts, images and lists directly on the page.

Support after launch

After the included support period, IDM can choose a monthly package of €100 for up to 5 hours (updates, small changes, help for editors), or ask for help when needed. Recommended for the custom website, which needs a technical update every few months.

Questions to discuss

  • Must the website run only with European companies, or is data stored in the EU enough?
  • Are both languages needed, or could one be enough?
  • Features beyond today's website are planned together with the new design and the page structure.

Assumptions

  • The final design has up to about 15 page templates.
  • Content is moved as it is; rewriting or translating is not included.
  • IDM provides access to WordPress (or its export), Google Analytics, Search Console and the domain.
  • Two review rounds are included. New features or extra templates are quoted separately.
  • The price is based on today's website. If the new design or structure changes the scope noticeably, the price is adjusted before the work starts.
  • Hosting and platform prices are 2026 list prices and estimates; they are confirmed on the providers' pages before signing. Sources: Webflow, Cloudflare Workers, Scaleway, Bunny.net, Exoscale.
